# Enterprise-SAP-Cloud-Security-Platform
Enterprise SAP Cloud Security Platform demonstrating IAM, RBAC, JML, SoD, AWS Security, CloudTrail, CloudWatch, and Infrastructure as Code.
The project demonstrates the design and implementation of an enterprise SAP Cloud Identity and Access Governance Solution on AWS using Security best practices

## Focus Areas

- SAP Security
- Identity and Access Management (IAM)
- Role-Based Access Control (RBAC)
- Joiner-Mover-Leaver (JML) Process
- Segregation of Duties (SoD)
- AWS Security
- CloudTrail and CloudWatch
- Infrastructure as Code
