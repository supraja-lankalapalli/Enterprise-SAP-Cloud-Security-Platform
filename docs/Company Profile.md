# Company Profile

## Company Overview

SL Cloud Technologies is a global enterprise specializing in cloud computing, digital transformation, enterprise software solutions, and IT consulting services. The organization provides secure and scalable technology solutions for clients across multiple industries while maintaining high standards of security, governance, and compliance.

To support its global business operations, SL Cloud Technologies uses SAP S/4HANA as its Enterprise Resource Planning (ERP) platform and Amazon Web Services (AWS) as its cloud infrastructure provider.

## Business Departments

SL Cloud Technologies consists of the following business departments:

Each department has specific business responsibilities and receives access only to the SAP applications and AWS resources required to perform its job functions.

---

## Security Strategy

To protect business-critical information, SL Cloud Technologies follows enterprise security best practices including:

* Identity and Access Management (IAM)
* Role-Based Access Control (RBAC)
* Principle of Least Privilege
* Multi-Factor Authentication (MFA)
* Segregation of Duties (SoD)
* Joiner, Mover, Leaver (JML) lifecycle management
* Continuous monitoring using Amazon CloudWatch
* Auditing using AWS CloudTrail
